# WechatVibe 1.4.0

本版是 nizitao 自用分支相对上游 v1.3.6 的增量发布，包含新功能、稳定性修复，以及完整的本机数据读取层 Rust 移植。上游的功能说明、下载安装、隐私与免责声明仍以上游仓库为准。

## 新增

- **思考过程查看格**：人物画像新增「思考过程」卡，位于关系倾向下方、互动风格右侧并与其等高。卡片右上角提供全屏 SVG 按钮（放大查看完整文本，支持遮罩点击与 Esc 关闭）和复制按钮（剪贴板 API 失败时回退 textarea，再失败给出提示）。文本取自最近一次 API 分析的模型推理，写入结果库前由本机 DPAPI 保护的 AES-GCM 加密，读取时解密后以 `textContent` 展示（不注入 HTML）；密钥缺失/损坏时明确报错，不退回明文。
- **导出聊天报告**：把当前会话已加载的消息、逐条标签与人物画像生成自包含 HTML 文件，全部在本地浏览器侧拼装，不上传、不额外落盘。
- **主题色可选**：设置 → 通用设置提供绿（默认）、蓝、黄、红四色，主窗口与沙箱军师窗口同步，选择随界面设置保存。
- **Rust 入口**：新增 `rust/app`，`Start.bat` 可直接启动 Rust 编排层（自检 / 启动后端 / 拉起窗口 / 清理），不再回落 Electron 入口；无构建产物时仍自动回落原路径。

## 优化与修复

- **思考模型的推理过程不再被当成卡死**：推理 delta 走独立通道，既作为进度保持等待状态活跃，又不进入 JSON 正文解析流；推理用尽输出预算时明确报截断，不再退化成格式错误后反复重试。覆盖 OpenAI Responses 与 Chat Completions。
- **启动修复**：`port_conflict` 判定放宽（`health()` 已验证身份时不再强制 TCP owner PID 等于刚启动的子进程）；Rust 入口正确传递 `WECHATVIBE_PYTHON` 等环境变量，避免窗口初始化被误判为「安装正在更新」。
- **本地标签大面积留白**（上游 [#35](https://github.com/tswawa/WechatVibe/issues/35)）：调整首选概率与领先次选阈值，整行可见率从 19% 提升到 65%。
- **本地画像少算 5 题**：由已训练的分类器接管，二阶段细分改为同层合并前向。
- **分类器升级**：MBTI 线性头升到 v3（test 96.88%），关系分类器升到 v3（test 90.57%、盲测 92%）。
- **Node 版本**：启动脚本优先使用 Node 24，消除版本警告。

## Rust 化进度

`native-reader/` 全部完成并逐条证明等价：6 个 bridge crate（4,062 条录制用例）、`SqliteShard` + `ContactStore`（201 条金标准操作）、`snapshot`（双目录差分 30/30）、`discovery` 路径配置（26/26）、`service` 解密热循环（22/22）、`NativeService` fixture 模式（21/21）。Win32 / live 路径依赖活桌面状态，按合成数据做单元自测，不声称与原版等价（见 `rust/DECISIONS.md` 的 ADR-017 至 ADR-019）。

`bridge/` 首批三个纯逻辑模块已移植：`message_contracts`（59/59）、`message_results`（446/446）、`profile_signals`（595/595）。

## 使用与升级

源码构建请用 `Start.bat`；已有数据目录、分析结果与模型会保留。本地分析需要 Laya 模型，可用 `npm run setup:models` 下载；只用 API 模式可跳过。
