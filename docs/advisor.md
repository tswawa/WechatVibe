# 助手仓库与聊天助手

左侧助手图标进入“助手仓库”，可以启用预设或创建自己的 Agent，编辑名称、欢迎语、提示词和 Skills。“人物画像”旁的“聊天助手”按钮展开同一应用窗口内部的固定宽度右侧面板，两侧共用标题栏和窗口边界；表情按钮保持原用途。预设“狗头军师”的模板名称独立于聊天入口。空会话显示自定义欢迎语和居中输入框，已有记录时显示时间线。对话、草稿和已生成结果按微信账号、会话及 Agent 保存。

仓库不显示引擎状态或预设标记。每张助手卡片都提供编辑和删除，包括内置助手；删除内置助手后重启不会自动恢复，删除正在运行的助手会停止其当前任务。仓库可以删空，并可再次新建助手。

输入 `/reset` 重置当前助手对话。窗口不提供拖动宽度、顶部模板胶囊、新话题、搜索或深度思考开关。点击当前 Agent 名称可以切换仓库中启用的模板。助手回复下不再显示“复制”按钮，文字仍可选中。切换到人物画像页会保留助手面板及正在进行的回复；更换微信账号、会话或 Agent 时仍按各自归属隔离。

新建或编辑助手时，技能按每列五项、每组两列排列，后续项目向下延续并通过列表滚动查看。“技能”标题右侧的“移除技能”切换移除模式；点击已选择技能旁的 × 从当前助手取消选择，保存后生效。取消编辑不会删除共享资料，也不会影响其他助手。

## 潜台词与沟通建议

本 fork 把原先位于「人物画像」页的「潜台词与沟通建议」搬进了助手：内置技能「潜台词与沟通建议」与内置助手「沟通参谋」随应用提供，选中后由助手用它自己的模型解读当前会话的潜台词（逐条给出表层说法、可能的真实意图、手法与语气），再给局势判断和可执行的沟通建议，并附上可以直接发出的回复草稿。默认按普通联系人给建议；说明是与领导或上级时改用更稳妥、留余地的说法；证据不足时会直说不确定。

如果这个会话此前生成过同一份分析（`POST /api/model-guidance` 留下的结果），助手会在本轮资料末尾看到它——场景、逐条潜台词、局势、建议与回复草稿——可以直接引用，不必重新分析。没有存量结果时，助手会被告知「尚无结果」，按所选技能自行分析当前会话资料。这部分内容与聊天资料共用同一个上下文预算，过长时按原有分层压缩处理，不会挤掉原文摘要。

## 导入助手

仓库只有“新建助手”入口，点击直接打开导入窗口，没有自定义创建模式或模式切换。导入支持 GitHub 仓库、tree 或 SKILL.md blob 地址，以及本地 SKILL.md、技能目录和 ZIP。可以先读取预览并编辑名称、说明、欢迎语和提示词，也可以在填写有效 GitHub 来源后直接点击“导入并创建”。导入失败保留表单，取消不创建卡片，重试不会重复创建；已有助手继续可以编辑。

导入器解析安全 YAML 元数据、包内引用与许可证，保留完整入口和参考原文，记录固定提交或内容摘要。脚本、ChatLab、技能长期记忆及二进制资料不执行；存在这些依赖时需要确认“使用只读适配版本”。这一状态表示分析方法与允许的文本资料可用，不表示原仓库所有工具功能都已接入。

每轮通过本地检索提供最多三篇预算内的完整参考资料，不额外调用模型分类，也不将整个资料包拼入系统提示词。超出本轮预算的参考不截断、不伪称已读。模型仍只允许读取当前托管微信资料文件，没有增加命令、文件写入、网络或任意文件读取权限。

助手和固定版本的技能包原子保存。重复导入同来源、同版本会复用已有助手，不覆盖其编辑和历史；新版本建立新的助手。旧版配置首次修改前在 `.local/advisor/config.v1.backup.json` 保存备份，旧助手与技能 ID、删除标记和对话关联保持不变。

发送后立即显示当前提问，在其下方显示一个持续更新的等待、思考或回答状态；正文逐步显示。提交失败保留原问题和草稿，重试沿用原请求编号；切换会话或重开窗口时使用已保存结果恢复，不重复添加同一提问。

## 源码运行

使用项目指定的 Node.js 和 Python 环境执行：

```powershell
npm ci
npm run setup:advisor-engine
npm run build:advisor-ui
npm start
```

标准应用构建会纳入固定的 OpenCode `1.18.34` 引擎和已编译界面，用户无需单独安装 OpenCode。已有本地 Laya 功能继续使用原来的独立模型包。军师自由对话使用设置中保存的生成式 API，或 Ollama 兼容接口；本地分析模式也可以使用保留的 API 连接。

## 资料与模型

- 每个微信账号、会话拥有独立托管资料。首次使用分页读取全部可读历史，后续只追加新消息；切换 Agent 共用该资料。
- 普通聊天已读取并验证的消息会直接同步到托管资料。完整窗口可直接建立资料；已完整托管的会话通过重叠消息追加新内容，重复发送不再扫描旧历史。只拿到首屏且缺失较早历史时，首次使用补齐一次；缺口、回退或内容变化会重新整理，不能把最近几十条当作全部聊天。
- 助手准备阶段复用普通聊天刚验证的账号绑定，绑定短期有效，来源释放、目录切换和账号清理立即失效。最终保存仍重新确认真实来源。
- 托管资料完整保存原文、发送者、时间及可用引用。模型输入超限时自动分段和分层压缩，保留覆盖记录；摘要不替代原文。
- 只有用户提交问题时才生成回答，必要时压缩；失败或停止保留已生成片段及上次可用资料。界面不显示读取数量或资料管理流程。
- 系统提示要求每轮通过 OpenCode 原生 `read` 工具读取当前会话资料，截断后按实际返回的末行继续。读取与回答由模型处理，程序不以是否读取或分页覆盖情况拦截回答，正文正常流式显示。模型需要支持工具调用。
- 一轮运行固定上下文版本，新消息供下一轮使用。Agent 自己的建议和推测不会写入公共事实摘要。
- OpenCode 保存军师多轮对话；本机 SQLite 和界面缓存只保存显示投影。取消或失败的未完成轮次从后续原生历史中排除。

## 权限与隔离

军师仅使用当前会话资料和用户选定的 Skill 文本，生成建议和可复制回复。原生会话仅精确允许读取本轮资料文件，其他文件读取、命令、文件修改、网页访问、插件、MCP、子代理及微信发送均禁用。模板和聊天内容不能扩大这些权限。

引擎只从项目内固定路径加载并校验大小及 SHA-256；账号数据、HOME、配置、缓存及运行目录独立。不会继承开发用 OpenCode、Claude 或其他工具的认证文件和全局配置。引擎服务使用随机本机端口和密码，界面只访问受控业务接口。

军师面板在主窗口内部使用独立 WebContentsView 和最小权限的 preload，会话运行在仅允许脚本的隔离 iframe 中，不直接联网或接触密钥。它不能调用主窗口的软件更新、目录选择或退出接口。Markdown 经过严格净化，图片、链接、脚本和 HTML 事件均不能触发外部动作。复制由用户点击执行。

清除账号时会先停止该账号的任务与引擎，排空写入，再删除托管资料、摘要及军师原生会话；其他账号与微信源数据库不受影响。

## 验证范围

合成检查覆盖首次全量读取、过滤空页、跨分片、长消息、共享压缩、取消、账号及模型切换、原生权限拒绝、持久化恢复、HTTP 边界与界面桥接。原生引擎使用本地合成服务验证五种协议映射和停止后的历史恢复。

真实服务商的摘要准确度、响应速度及真实聊天建议质量仍需实端验收。输入字符预算为保守估算，模型实际 token 容量和原生对话压缩由所选模型及 OpenCode 管理。
